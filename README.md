# Birendra Sah | SecureFuture Advisor

Static public portfolio for GitHub Pages. There is no admin page, login, browser storage, or editable public data in this project.

## Add Photos

Put your public images in the `assets` folder using these names, or change the paths in `script.js`:

- `profile.jpg`
- `credential.jpg`
- `current-company-logo.png`
- `previous-company-1.png`
- `previous-company-2.png`
- `top-advisor-award.jpg`
- `500-families-protected.jpg`
- `life-insurance-specialist.jpg`
- `certificate-1.jpg`
- `certificate-2.jpg`

Edit the public text, contact details, and image paths only in the `data` object at the top of `script.js`, then deploy the files to GitHub Pages.

## Important Privacy Note

Anything deployed to GitHub Pages is public. Visitors can view or download public images and inspect the website source. Never upload passwords, private documents, policy numbers, personal ID numbers, signatures, QR codes, or private contact details.
